# Routes

Проект построен на микросервисной архитектуре на Go.  
Все сервисы используют стандартный `http.ServeMux` и обмениваются данными в формате JSON.

## Normalizer Service

**Порт:** `8081`

| Метод | Путь | Описание |
|---|---|---|
| POST | `/normalize` | Нормализация текста, частота слов |
| POST | `/cooccurrence` | Анализ совместной встречаемости слов |
| GET | `/health` | Проверка работоспособности |

## Scraper Service

**Порт:** `8082`

| Метод | Путь | Описание |
|---|---|---|
| POST | `/scrape` | Парсинг отзывов (html/api/js) |
| GET | `/health` | Проверка работоспособности |

## Storage Service

**Порт:** `8083`

| Метод | Путь | Описание |
|---|---|---|
| POST | `/jobs` | Создать задачу парсинга |
| GET | `/jobs/:id` | Получить задачу по ID |
| POST | `/words` | Сохранить слова с частотами |
| GET | `/words?brand=...&limit=...` | Получить топ слов по бренду |
| GET | `/health` | Проверка работоспособности |

## Scheduler Service

**Порт:** `8084`

| Метод | Путь | Описание |
|---|---|---|
| POST | `/schedule` | Поставить задачу в очередь Redis |
| GET | `/health` | Проверка работоспособности |
